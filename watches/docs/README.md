# watches: the talk's own docs

What is true of this talk only. The house rules for every STEM talk (theme,
illustrations, WebGL, legibility, how to work in the repo) are in
[`stem/docs/`](../../docs/README.md). When to read each doc is in
[`stem/AGENTS.md`](../../AGENTS.md), "House docs: read before you act"; keep
the two lists in step.

- [slide-patterns.md](slide-patterns.md): how a slide is built: the theme on a
  slide, the timekeeper card, clicks, speaker notes, what fits, borrowed assets
- [watch.md](watch.md): the live watch (files, design, rim screws, frontmatter
  keys, the explorer, zoom line widths, budgets) and the diving board
- [article.md](article.md): the article at `/article`: the narration, its figure
  markers, what a figure shows, the sliders, the code, the static page
- [measurements.md](measurements.md): what the timekeepers, the cover watch,
  balance rim motion, and the diving board measure at the back row
- [rough-slides.md](rough-slides.md): the talk's outline, as working notes.
  Check each claim before it goes on a slide
- [packages.md](packages.md): dependency constraints and the UnoCSS build
  override
