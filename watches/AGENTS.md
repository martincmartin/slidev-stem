# What Every Nerd Should Know About Watches

The house rules for every STEM talk are in `../AGENTS.md` and `../docs/`. This
talk's own docs are in `docs/`.

## Docs: read before you act

| Before you…                                                                                                                                    | Read                                                 |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| add or change a slide                                                                                                                          | `docs/slide-patterns.md`                             |
| change the watch (`watch/`, `art/`, its frontmatter, `global-bottom.vue`) or the diving board                                                  | `docs/watch.md`, and `../docs/webgl.md` for `webgl/` |
| write or change a slide's narration, or change the article (`addons/narration/`, `components/FigureLayer.vue`, `watch/article.ts`) or build it | `docs/article.md`, and `../docs/export.md`           |
| change a drawing, or claim that one is legible                                                                                                 | `docs/measurements.md`, `../docs/legibility.md`      |
| choose what the next slide says                                                                                                                | `docs/rough-slides.md`                               |
| update packages or remove a dependency override                                                                                                | `docs/packages.md`, and `../docs/talks.md`           |
