# Sundial time-lapse — raw working files

These three files are the provenance of `deck/public/timekeepers/sundial-timelapse.mp4`
(205 KB), which is the only one the archive deck actually loads. They sat loose in the
project root until 2026-09-21, when the live deck dropped the video and they were moved
here so the trail survives.

```
Sun dial time-lapse (no watermark).mp4   7.4 MB   as downloaded
Sun dial time-lapse clip.mp4             5.7 MB   cropped and trimmed
Sun dial time-lapse 2x.mp4               6.5 MB   ... and sped up 2x
  -> deck/public/timekeepers/sundial-timelapse.mp4   205 KB   re-encoded for the web
  -> deck/public/timekeepers/sundial-timelapse.jpg    27 KB   poster frame
```

**The .mp4 files here are deliberately NOT committed** (see the project `.gitignore`):
19.6 MB of intermediates that can be rebuilt from the source below, in a repo whose
entire deck is under a megabyte. This README is committed, so the trail survives even
where the files do not.

**Source.** [Sun Dial Time Lapse](https://archive.org/details/SunDialTimeLapsenoWatermark)
— NatureClip, 2012, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Changes
made: cropped, trimmed, sped up 2x.

**If the video is ever re-adopted, the credits slide has to come back with it.** It was
deleted from the live deck on 2026-09-21 as part of the same change, because the sundial
clip was the only borrowed asset in the talk and a CC BY licence asks for credit on every
copy performed, not just every copy distributed. Everything else in the deck was drawn
for it.

**Why the video was dropped.** Not a licensing or a quality problem. The live deck now
uses one drawing set for all four cards (§14), and a photograph of a sundial next to
three line drawings is the one card that does not belong to the set — which is also why
the sixteen comparison slides drew the sundial instead of playing the clip.
